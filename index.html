Инструкция по использованию ✖
  • Добавление и редактирование: Нажмите «+ Добавить» для создания карточки. Кнопка ✏️ открывает настройки: там можно перенести тайтл в другой раздел, изменить статус, указать ссылки для просмотра, добавить сезоны или настроить количество серий.
  • Отметка просмотра: Нажимайте на квадратики серий, чтобы отметить их.
    Кнопка "+1 Серия" сама находит первую непросмотренную серию и автоматически её отмечает. Когда все серии просмотрены, тайтл сам перейдет в статус «Просмотрено».
  • Кнопка Поиска (Аниме): В разделе Аниме есть кнопка 🔍. Чтобы она работала, зайдите в «Управление данными» и вставьте базовую ссылку вашего любимого сайта для поиска.
  • Ссылки на просмотр: В окне редактирования можно вставить несколько ссылок (каждую с новой строки). В карточке появится удобный выпадающий список со всеми сайтами.
  • Полнометражные фильмы (Аниме): Фильмы и спецвыпуски автоматически получают красивые цветные метки (ФИЛЬМ, OVA, ONA), а счетчик серий для фильмов скрывается. Вы также можете вручную отметить чекбокс «Полнометражка» в настройках аниме.
  • Сортировка (Drag & Drop): Зажмите левую кнопку мыши на любой карточке и перетащите её выше или ниже, чтобы выстроить свой личный топ (работает везде, кроме статусов "Отложено" и "Брошено").
  • Умный импорт Аниме: Для переноса базы с Shikimori загрузите сначала XML файл (подтянет типы OVA/Фильмы, статусы и точное количество серий), а сразу за ним загрузите JSON файл (переведет все названия на русский язык). Трекер сам склеит данные воедино.
  • Управление данными (Бэкап): Обязательно сохраняйте резервную копию трекера! Нажмите «Скачать текущий бэкап», чтобы получить JSON файл со всеми вашими сериалами, фильмами и мультфильмами. С его помощью можно легко перенести данные на другое устройство.
